# Melbourne Airbnb Listing Price Prediction 

Predict the listed nightly price of Airbnb properties in **Melbourne** using property and host characteristics.  

---

## 📌 Project Goal
Build regression models to predict **Airbnb listing prices** based on available listing features (e.g., room type, location, amenities, host activity, review metrics).

---

## 🧾 Dataset
Data is provided via a Kaggle competition and includes:
- `train.csv`: training dataset containing features + target `price`
- `test.csv`: test dataset containing features only
- `sample_submission.csv`: required submission format
- `metaData.csv`: feature descriptions / additional information (if provided)
